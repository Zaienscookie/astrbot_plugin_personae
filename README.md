# astrbot_plugin_soulbook · SoulBook 灵魂书卷

自动记录每个与 bot 对话的用户信息，并提供独立端口的 WebUI 管理面板。

## 功能

- **自动记录**：每个发言用户的昵称、所在群、消息数、首次/最近活跃时间、最近消息
- **自定义字段**：为每个用户添加任意字段（生日、爱好、备注等）
- **备注**：追加时间线备注，最多保留 50 条
- **指令操作**：群里直接用指令查看/设置
- **WebUI 面板**：独立端口访问，浏览器管理所有用户数据

## 安装

将本目录放入 `data/plugins/` 后，在 AstrBot WebUI 中启用插件并重载。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/画像` | 查看自己的画像 |
| `/画像 @某人` | 查看对方的画像 |
| `/画像设置 字段 值` | 给自己设置字段，如 `/画像设置 生日 1月1日` |
| `/画像设置 字段 值 @某人` | 管理员设置他人字段 |
| `/画像备注 文本` | 给自己追加备注 |
| `/画像列表` | 查看当前群用户活跃排行 |

## WebUI

插件启动后会自动监听一个独立端口（默认 `8799`），访问：

```
http://服务器IP:8799/
```

面板功能：

- 统计卡片（用户数 / 消息数 / 覆盖群数）
- 搜索（昵称、ID、字段、备注）
- 排序（活跃 / 消息数 / 昵称）
- 详情查看与编辑（自定义字段增删改、备注管理）
- 手动添加用户、删除用户

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `webui_port` | `8799` | WebUI 端口，改端口后在插件配置页保存并重载插件 |
| `webui_host` | `0.0.0.0` | 监听地址，`0.0.0.0` 允许所有网段访问 |
| `enable_record` | `true` | 是否自动记录用户 |
| `admins_id` | `[]` | 可修改他人画像的管理员（不填则只有本人能改自己的） |

## 数据存储

数据保存在插件目录 `data/user_profiles.json`，JSON 格式，可直接备份迁移。
